## 🚀 Project Overview

**AI-FEA-Predictor** is an AI-powered engineering analytics application that uses a **Machine Learning surrogate model** to predict structural stress without repeatedly running computationally expensive FEA simulations.

The application allows users to modify engineering parameters such as:

- Plate width
- Plate thickness
- Hole diameter
- Applied tensile force
- Material yield strength

and instantly obtain:

- 🔥 Predicted Von Mises Stress
- 🛡️ Factor of Safety
- 📊 Stress sensitivity analysis
- 📈 Parametric trends
- ⚡ AI inference time
- 🚦 Structural stability indication

The project demonstrates how **Artificial Intelligence can accelerate repetitive engineering simulations**.
